In the modern retail industry, accurate sales forecasting is crucial for optimizing inventory management, strategic planning, and maximiz- ing profitability. This research project devel- oped a robust machine learning model to pre- dict the sales of products across various Big Mart outlets by employing advanced regression techniques. A comprehensive dataset containing product attributes such as item weight, visibil- ity, type, MRP, and outlet characteristics includ- ing identifier, size, location type, and establish- ment year was utilized for this analysis.
The dataset was preprocessed using mean and median imputation for missing item weight val- ues, mode-based imputation for outlet size based on outlet type, and linear interpolation for zero visibility values. Feature engineering techniques, including categorical encoding and the creation of new features like outlet age, were applied to enhance data quality and model performance. The XGBoost Regressor algorithm was then de- veloped to predict sales amounts based on the cleaned dataset.
The performance of the model was evalu- ated using mean absolute error (MAE) and R- squared metrics. The model achieved an MAE of 714.42, indicating that predictions are accu- rate within approximately $714 of actual sales values, with an R-squared score of 0.596.
Overall, this research demonstrates how ad- vanced machine learning techniques and feature engineering can be utilized to perform sales pre- diction and highlights the importance of proper data preprocessing and feature selection for such analyses.
